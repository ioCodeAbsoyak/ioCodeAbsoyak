## 🔒 My work (sorry, it's all private!)

Almost everything I build is client or championship work, so the repos are private. Here's what's in there instead:

| Project | What it does | Stack |
|---|---|---|
| ⏱️ **h2oAdmin** ([timingcenter.com](https://timingcenter.com)) | Race timing and results management for H2O events: lap passes, penalties, standings, TV graphics output and weather/wave data | C#, SQL Server, AWS (S3, ALB, Route 53) |
| 📡 **Live rover tracking** | Real-time GPS tracking of racing boats: a desktop monitor, a data relay and a browser map showing positions, speed, battery and automatic lap times from finish-line crossings | C# WinForms, Python, WebSockets, QuestDB |
| 🗺️ **h2oLiveMap** | Browser-based live race map and replay: circuit, buoys, boat trails and race flag events on a timeline. Display-only, so it works with any GPS source | HTML / JS, Leaflet.js |
| 👁️ **Finish-line boat detection** | Computer vision that spots boats crossing the finish line from a live camera feed and fuses the result with GPS | NDI, Faster R-CNN / YOLO, CUDA |
| 📺 **Broadcast timing graphics** | Cinegy Title templates for live race-timing displays: animated leaderboards, sliding and cascading timing rows, and scripted frame-rate conversion | Cinegy Titler XML, C# |
| ☁️ **Cinegy Cloud modernisation** | Moving a broadcast platform towards microservices, with paginated REST APIs and token-based auth | Docker Swarm, REST, .NET |
| 🏎️ **[LapData](https://lapdata.ai)** | AI agent for motorsport timing data, trained on five seasons of real F1H2O and Aquabike results: ask questions in plain language, get answers and predictions | LangChain, FastAPI, Ollama, ChromaDB, XGBoost, Docker Compose |
| 🖥️ **Offline local AI stack** | A fully private LLM setup that runs on my own GPU (Ollama + Open WebUI), plus edge-AI experiments on Raspberry Pi 5 with a Hailo accelerator | Ollama, Docker, Hailo, VLMs |

> 💡 Want to know more about any of these? Get in touch, I'm happy to walk you through them.
